# Yehui Tang

Personal website for research, writing, and a resume.

[yehui-tang.github.io](https://yehui-tang.github.io/)

## Update the website

Edit the homepage in `docs/index.html`. The Blog, Publications, and Resume pages each have an `index.html` in their own folder under `docs/`. Typography and layout are in `docs/assets/site.css`. Run `python3 -m http.server --directory docs` to preview the site locally.

GitHub Pages publishes the `docs/` directory from the `master` branch.
