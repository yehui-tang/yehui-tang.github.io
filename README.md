# Yehui Tang

Personal website for research, open-source projects, news, tutorials, and writing.

[yehuitang0316.github.io](https://yehuitang0316.github.io/)

## Update the website

Edit the five sections in `docs/index.html`. Typography and layout are in `docs/assets/site.css`. Run `python3 -m http.server --directory docs` to preview the site locally.

GitHub Pages publishes the `/docs` folder from the `master` branch. The original Academic Pages template remains in the repository root.
